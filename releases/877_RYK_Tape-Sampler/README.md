# RYK B77 Tape Sampler

The B77 turns the Workshop Computer into a two-track mono tape sampler. It can record about 90 seconds of sound, play it forwards or backwards at variable speed, and crossfade between the two tracks. Recordings remain on the card when the power is switched off.

## Quick start

1. Connect a sound to **Audio In 1**.
2. Set **Y** towards the track you want to record.
3. Hold the switch **up** to record, then return it to the centre to stop recording.
4. Tap the switch **down** to start or stop playback.
5. Turn **Main** away from the centre to choose playback direction and speed.
6. Use **Y** to mix between Track A and Track B.

Keep the input level sensible: the top LED should only peak occasionally.

## Controls

- **Main - Speed and direction:** Centre stops the tape. Turn in either direction to play forwards or backwards at variable speed.
- **X - Start position:** Sets the point to which playback returns when it is reset or retriggered.
- **Y - Track mix / record select:** Crossfades between Track A and Track B and determines which track receives a recording.
- **Switch up - Record:** Records from the current tape position while held.
- **Switch centre - Stop recording:** Ends recording.
- **Tap switch down - Play/stop:** Starts or stops playback.
- **Hold switch down - Play/stop and reset:** Starts or stops playback and returns to the start position.

## Inputs and outputs

- **Audio In 1:** Recording input.
- **Audio Out 1:** Mix between Track A and Track B.
- **Audio Out 2:** Complementary mix between Track B and Track A.
- **CV In 1:** 1V/oct control of playback speed.
- **CV In 2:** CV control of the track mix.
- **Pulse In 1:** Retriggers playback from the start position.
- **Pulse In 2:** Gated playback from the start position.

## Erasing recordings

To erase audio, hold the switch **down while starting the card**. The position of **Y** selects Track A, Track B, or both tracks. Erasing takes about 15 seconds per track, so allow the process to finish before using the sampler.

## Patch ideas

- Record related sounds onto both tracks, then animate the crossfade with **CV In 2**.
- Use **Pulse In 1** to turn a long recording into a rhythmically retriggered phrase.
- Patch pitch CV to **CV In 1** for tuned tape-speed changes.
- Set a start point with **X**, reverse playback with **Main**, and use gated playback for chopped tape effects.

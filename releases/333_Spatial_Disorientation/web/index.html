Spatial Disorientation

0.4.0-beta3 · Twin Orbits / Mixer / Disorientation · separate mode settings · beta · preset files v7 · 64-tap HRTF + room cues · two sources moving around your head

Connect your Workshop Computer

Use a USB-C data cable. Close Serial Monitor/other apps. Use Chrome or Edge on desktop with MIDI and SysEx permission; iOS is unsupported. Select “Spatial Disorientation” for both MIDI ports below.

Connect the card, then enable MIDI.

Timing measurements appear after connection.

A: turquoise · B: amber. Headphones recommended.

Main: position · X: speed/direction (centre stops; free-running max 1.5 turns/s) · Y: distance
Switch up: linked · middle: opposing · down: reset phase

Continuous Mixer height

Move each source between −40° and +40°. Apply includes heights with the other settings. Send heights auditions only the two heights; Save to card and preset export include them.

Startup restores saved Mixer heights; older settings start Level.

Disorientation vertical movement

Height centre and excursion apply to both sources along their own phases. Excursion zero holds the centre height; centre 0° with zero excursion preserves the horizontal path. These settings use Apply and Save to card.

Uphill direction: 0° front, 90° right, 180° back, 270° left; diagonals are continuous. For Twin Orbits, height 0° and tilt 0° retain beta1. In Disorientation, tilt zero preserves the existing height/bob. Tilt adds direction-linked height and changes the horizontal projection, while keeping path distance. Disorientation bob is added; combined heights clip at ±40°. Apply sends these settings; there is no automatic send. Export beta1 presets before beta2 Save: beta1 cannot read flash v8 or v7 preset files.

Fig8 rises/falls with its lobes; Pendulum lifts at its ends; Wander eases between repeatable height targets. Heights stay within ±40°. 8mu fader 8 retains motion amount.

Twin Orbits settings

Apply changes the running sound. Save to card stores the applied settings and briefly fades the audio out. Reset to init applies factory editor settings; use Save to card to retain them after reset. Mixer placements applied here rearm panel pickup. Each mode has its own saved settings.

Room reflections: zero gives the dry HRTF. Try 30–50% for outside-head listening; Y increases the reflected/direct balance. Front/back placement remains listener-dependent.

Export downloads the settings currently shown here. Import loads settings into the editor only; Apply auditions them, then Save to card makes them persistent. Files work offline. Twin Orbits presets contain six core settings plus height, uphill direction and tilt; Disorientation adds movement, vertical centre/excursion and slope direction/tilt. Older presets default to zero tilt. Mixer presets also contain both source positions, distances, panel levels and continuous heights. Read captures current Mixer placements and heights before export; Save captures them for startup. CV, Fig8 depth/excursion/rate/freeze and Twin Orbits motion/phase are excluded. Modes have separate saved settings.

For direct 8mu use, connect it to the card and reset; the editor is used separately. 8mu never writes flash automatically; its live height changes return to saved values on reboot. Set matching heights in a separate editor session and Save to retain them. Editor-session heights and live Mixer placements are captured by explicit editor Save; other 8mu configuration overrides remain live only. In Twin Orbits, tap D to switch pages: normal faders 1/2/3 = speed/distance/separation; height page = height/tilt/uphill direction. Faders 4–8 retain room/A/B/strength/motion amount. LEDs 1–3 briefly identify normal; LEDs 6–8 identify height. Both pages use pickup; hold D for timing without switching. Live height/slope return to saved values on disconnect/reset and do not write flash. In Fig8, faders 1–8 control speed, excursion, phase separation, room, A/B trims, strength and motion amount. B toggles motion takeover of Main; A resets/recentres; C held freezes; tap D cycles Fig8/Pendulum/Wander, hold D for timing. LEDs 1/2/3 briefly identify the movement. Pitch directly places Disorientation front/back depth; roll turns its path left/right. Orbits uses pitch/front-back and roll/left-right as a directional pointer. Roll follows the lowered edge: right edge down moves right, left edge down moves left. Holding a pose holds placement; yaw is ignored. Near Orbits neutral, the last direction is held. In Orbits, fader 8 sets tilt sensitivity: lower settings need more tilt, and zero returns to the captured anchor. In Disorientation it scales pitch depth and roll rotation. A captures neutral/Main. Pitch/roll do not directly edit height/slope. Main/X/Y require pickup when returning from 8mu ownership. In Spatial Mixer, faders 1/2/3 control selected distance/level/position; fader 8 controls selected-source height continuously from Below through Level to Above, with pickup. Buttons A/B select sources, and motion is unused. Hold Down during startup and choose with Main: lower third Twin Orbits (no LEDs), middle Spatial Mixer (left LEDs), upper Disorientation (right LEDs). Release to confirm; normal boot always chooses Twin Orbits. Mixer restores its saved heights. Disorientation uses its separately saved vertical centre/excursion; old presets remain horizontal. Ear filters derive from Bill Gardner and Keith Martin’s MIT KEMAR measurements (MIT Media Laboratory, 1994), with separate timing and room cues. This is a short-filter approximation, not personalized HRTF rendering.

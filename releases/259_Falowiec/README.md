# 259: Falowiec - West Coast Complex Oscillator (WIP)

A program card for the [Music Thing Modular Workshop Computer](https://www.musicthing.co.uk/Workshop-Computer/).

**Falowiec** is a dual complex oscillator inspired by classic 1970s West Coast synthesis with a spice of mellow & melodic bias - packed with instant inspiration for wavefarers lost among waves, seeking shelter under Falowiec\*.

*\*An untranslatable Polish word rooted in **waves**... and the name of the iconic 1970s brutalist wave-shaped apartment blocks in Gdańsk.*

## Features & Architecture
- **Principal & Modulation Oscillators** with pre-patched internal modulation routing
- **West Coast Timbre / Wavefolder** section for rich harmonic folding
- *More in progress...*

## Status
Work in progress - `.uf2` firmware binary and documentation coming soon.

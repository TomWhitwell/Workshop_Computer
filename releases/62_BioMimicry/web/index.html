Card storage

Your samples

Load recordings here, then pick them in the slots below. One file can be used as many times as you like — the card stores it once, so reuse is free.

On the card

Any WAV works, mono or stereo. Browser converts to the card's format (8-bit mono 48 kHz), trims silence and matches loudness.

Setting a slot to none removes it, so a mode with three slots filled plays a three-way round robin.

Each slot can be: 1. a recording the card already holds (USER 1, USER 2…) 2. one of its built-in recordings, 3. a file you have just loaded (NEW 1…), which will upload 4. None (unused)

Upload samples sends any NEW files and applies the mapping.

Update mapping only rewrites which slot plays what.

Revert to built-in above clears everything and reclaims the space.

Sample changes/mapping survive power off!

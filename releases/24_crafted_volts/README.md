
# Crafted Volts 

CV - get it? :)

A utility card for the WS Computer to manually set control voltages (CV)
with the input knobs and switch. It also attenuverts (attenuates and inverts)
incoming voltages.

Crafted Volts is developed in a different reposotory, visit [Crafted Volts](https://codeberg.org/briandorsey/mtmws_cards/src/branch/main/crafted_volts) for the code.

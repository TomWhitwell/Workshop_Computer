Local UF2 builder

Start the local server with python3 tools/web_uf2_server.py, then this button will build and download a complete custom UF2.

What gets generated?

The output header uses the same symbol names as the firmware: kVocalMarqueeOi, kVocalCbgbHeyHo, kVocalClub100NoFuture, and kVocalWhiskyLetsGo. The browser converts the audio; the local Python backend runs CMake and returns the finished UF2. If you are using this page without the backend, you can still download the processed WAVs and run python3 tools/build_custom_uf2.py --samples that-folder --clean.

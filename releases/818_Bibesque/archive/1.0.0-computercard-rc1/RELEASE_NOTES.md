# Bib for Workshop Computer — 1.0.0-rc1

Hardware-tested release candidate built from commit `7d2fcec`.

Included behaviour:

- Bib-inspired drive, wavefold, stereo delay, reverb, shimmer and freeze.
- Original-style clock quantisation, tape transport, multi-tap delay and
  automatic long-delay tape scaling.
- Page-specific LED display and active-page bipolar CV modulation.

Flash `bib_workshop_1.0.0_rc1.uf2` to the Workshop Computer. Earlier firmware
source snapshots and matching UF2s remain intact under `../../archive/`.

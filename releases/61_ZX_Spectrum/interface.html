Input mapping

Click an input on the left, then click a key to assign it.

CV Out 2 — memory probe

Outputs RAM[address] (0–255) as 0–5V on CV Out 2. Default 16384 = screen memory (flickers with the display). Try a game variable for a live CV.

Keyboard passthrough

off

While on, your keystrokes are sent as Spectrum keypresses. Letters, digits, Enter and Space map directly; use Shift for CAPS SHIFT and Alt for SYMBOL SHIFT. Shift+0 (or Backspace) = DELETE. (Click back on the page if focus is lost.)

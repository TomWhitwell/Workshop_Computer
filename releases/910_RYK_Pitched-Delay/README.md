# RYK 910 Pitched Delay

The 910 is a pitch-shifting delay for the Workshop Computer. It can shift repeats by up to one octave in either direction, create rising or falling cascades, and freeze the current delay buffer.

## Quick start

1. Connect a sound to **Audio In 1**.
2. Listen from **Audio Out 1** for a mix of the dry input and pitched delay.
3. Set **Y** for delay time.
4. Set **X** for feedback.
5. Turn **Main** to pitch the repeats down or up.
6. Hold the switch **up** and turn **Main** to change the dry/effect mix.

Keep the input level sensible: the top LED should only peak occasionally.

## Controls

- **Main - Pitch shift:** Sets the pitch of the delayed signal, from one octave down to one octave up.
- **X - Feedback:** Sets how much of the delayed signal is fed back into the effect.
- **Y - Delay time:** Sets the time between the original sound and the repeat.
- **Switch up + Main - Output mix:** Changes the balance between the dry input and pitched delay.
- **Switch down - Mute delay send:** Temporarily stops new sound entering the delay while existing repeats continue.

## Inputs and outputs

- **Audio In 1:** Audio input.
- **Audio Out 1:** Dry/effect mix.
- **Audio Out 2:** Pitched delay only.
- **CV In 1:** 1V/oct control of pitch shift.
- **CV In 2:** CV control of delay time.
- **Pulse In 1:** Freezes the current audio buffer.
- **Pulse In 2:** Gated effect send. Leave this input unplugged when it is not being used.

## Patch ideas

- For clean harmonised repeats, turn feedback fully down and set the pitch to a fifth, a third, or an octave below.
- Add feedback for cascading repeats which rise or fall in pitch.
- Pulse **Freeze** to catch a fragment, then change pitch and delay time while it loops.
- Use the gated effect send to place only selected notes or drum hits into the delay.

The manual points towards Tony Visconti-style pitched drums and Jon Hassell-style trumpet processing as useful starting points.

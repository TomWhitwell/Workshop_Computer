Connect over USB

Use a USB-C data cable. On your Mac, open this page in Chrome or Edge and choose MTM Sitar USB editor (it may appear as Pico or a USB serial device). Close Serial Monitor/other apps using the port.

The USB editor UF2 must be on the program card. Keep the Workshop System powered through its normal supply; a laptop USB connection does not power the whole system. Safari, Firefox and iOS are not supported. Serve this page from localhost or HTTPS.

Hold Down: knob assignments

Choose what each knob controls while the switch is held Down, then click Apply. During playing, hold Down and deliberately turn that knob to change the chosen sound setting. A tap still plucks once.

Release Down before applying webpage edits. After a held edit, return the knob through its previous normal position to regain Jawari, Swell or String control. If several moved knobs share an assignment, Y wins over X and Main. Save to card keeps your assignments after reset.

Sympathetic strings (taraf)

These twelve model strings are not plucked directly. They ring when the melody or an external input contains frequencies close to their tuned modes, creating the metallic halo. Each selector sets one string's fundamental note; its upper harmonics are generated automatically.

They keep this tuning when you change melody pitch or bend a note. Sympathy controls their level; Sympathetic duration controls how long they ring. Start with a preset, then adjust individual notes to suit your melody.

The Yaman preset is a twelve-string, equal-tempered adaptation of a published tuning. Its tonic (Sa, the home note) is D4, one octave above the default unpatched D3 melody. Duplicated notes are intentional: separate strings can reinforce the same pitch. The Original preset restores our earlier tuning; it is not a documented raga.

Presets apply all twelve notes immediately. Individual selectors need Apply. Retuning briefly fades and restarts the halo. Click Save to card to keep the applied tuning after reset.

Pitch CV calibration

Factory calibration remains active; user corrections adjust CV1 input and pitch CV output. You can enter manual offset (mV) and scale (ppm) below. For a two-point correction, use a known voltage source or meter and enter two distinct measured pairs at least 1000 mV apart. Input: X is the instrument reading and Y is the known source voltage. Output: X is the voltage measured with your meter and Y is the requested output voltage. Apply the calculated offset and scale fields, then Save to card.

Apply changes the running instrument. Save to card explicitly writes settings to program-card flash; Restore reloads the last valid save. Revert defaults changes the running state until saved. Factory EEPROM calibration is unchanged. Save only when needed to limit flash wear.

Remote Jawari, Swell and String edits use pickup: move the corresponding knob through its displayed value to regain control. CV modulation continues. Held Down uses the assignments above; release Down before applying remote changes. Reset of a primary control returns it to the current physical knob. Other resets use the displayed default.

Pick position changes where the next pluck excites the string; Pick release changes its softness. Halo level trims the sympathetic output without changing its feedback. Optional duration and resonator controls appear only when the connected firmware implements them.

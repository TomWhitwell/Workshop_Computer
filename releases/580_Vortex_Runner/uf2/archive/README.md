# Vortex Runner firmware archive

Earlier binaries are preserved for rollback and comparison. The catalogue's
curated download list excludes this archive.

- [Archived 26 October 2026](previous-versions-20261026/README.md): August baseline,
  October 8mu builds and the three earlier controller experiments, with checksums.
- [Archived 7 October 2026](previous-versions-20261007/): the earlier
  `Vortex_Runner_current_stable_8mu_filter_envelope_hp_20261003.uf2`, with its
  redistribution notice.

The current standard and 8mu editions are described in the
[main user guide](../../README.md#choose-your-firmware). They remain Beta
builds awaiting hardware verification; archiving older builds does not change
that status.

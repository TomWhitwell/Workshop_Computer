The original 0.4.1 experiment is identical to archived stable 0.4.1. Its source
includes the normal and additional torture-test pass records reported by Adrian
on 8 November 2026. The original 0.5 experiment is identical to current stable

Old build caches were moved with their source folders but are not portable and
are excluded from release packages. Reconfigure a fresh build directory if
rebuilding archived source. Archived firmware remains available for rollback;
only the current stable UF2 is listed in the catalogue metadata.

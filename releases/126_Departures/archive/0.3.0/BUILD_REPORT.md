# Departures 0.3.0 — stable release build report

Promoted 8 November 2026 at Adrian's request. This stable UF2 has exactly the
same bytes as the original 0.3.0 experimental build; SHA-256 is unchanged.
The original experiment is preserved in `archive/experimental/0.3/`, earlier
experiments in `archive/experimental/0.2/`, and 0.1.0 in `archive/0.1.0/`.
The validation below belongs to that original compiled 0.3 image; promotion
adds no new claim of an instrumented hardware timing measurement.

## Build and package

- RP2040 / `PICO_BOARD=pico`, default 2MB layout; fits 2MB and 16MB cards.
- Pico SDK 2.3.0, revision `98a542c1a62fb549ffb5d66a3e5892b06276b670`.
- ARM GNU Toolchain 15.2.Rel1 / GCC 15.2.1; C++17, Release, application `-O3`.
- Unchanged ComputerCard 0.4.0, RAM execution, 192MHz / 1.15V.
- Linker: FLASH 102,384 bytes; RAM 107,864 of 262,144 bytes; 2,048-byte
  core stack in SCRATCH_Y. USB stdio is disabled; no runtime flash writes.
- `uf2/Departures_0.3.0.uf2`: 204,800 bytes, 400 RP2040 blocks.
- SHA-256: `0e066ae6152f221d95c56cec10b89aff695a5c9702a8330b3df6db631144c841`.
- Packaging validates block magic, family, numbering, size, addresses and payload
  identity against `build/Departures.bin`. Checksum and full notices accompany it.

## Functional checks

Apple Clang 21 with AddressSanitizer and UndefinedBehaviorSanitizer passed all
inherited engine and external-input tests plus the new phrasing checks:

- Stored accents repeat unchanged, reproduce with the same seed, vary with
  different seeds, and remain bounded at about 75–100% of the 0.2.2 strike level.
- Every note mutation touches at most one note per phrase boundary and moves by
  exactly one scale degree, with no change to stored accents.
- At most one phrase plays an octave answer at a time. A complete round is
  followed by return home; resting phrases cannot also be octave answers.
- Higher and lower answers occur, including with octave transposition at either
  limit. Resulting melody pitches stay in MIDI 36–96 and in D Dorian.
- Hold prevents new answers and mutations; an existing answer finishes and returns.
- The dedicated accelerated-clock check observed 17 answers, 17 returns and
  81 single-step mutations, with stored accents unchanged throughout.
- Inherited tests cover shared-note phase/breath continuity, silent retuning,
  interrupted transitions, single-layer rests, clock stop/unplug, trigger timing,
  transposition, seeded audio, extreme input levels and effects decay.
- The two-minute extreme-input test passed with peak 1,997/2,047, 2,816 melody
  events and 479 chord changes. Evolution metrics retained the 0.2.2 counts.
- External-input RMS remains 0.4468 (−7.00dB) at default Y and 0.8200 (−1.72dB)
  at maximum Y for the existing modest mono sine test. Both jacks match; Y=0
  contributes no external audio. The stronger 0.2.1 send is retained.

## Three-minute preview

The deterministic 180-second render at default controls generated 150 beats,
214 melody strikes, six chord changes, eight shared-tone carries, four bell
rests and four bass rests. These counts match the 0.2.2 reference. It also
contains four octave answers, four returns and three single-step mutations.
The expression RNG is separate from the original seed sequence, preserving
pad/tide/rest decisions and note-event timing for the same input/seed.

## ARM timing estimate

Unicorn 2.1.4 / Capstone 5.0.9 executed 100,000 compiled callback samples with
fast clocks, manual and automatic chord changes, expression/answer decisions,
transposition changes, full effects and full-scale audio inputs. The second
half uses correlated input channels to exercise the hot mono send. Approximate
framework/IRQ overhead: 731 cycles. Budget: 4,000 cycles at 192MHz / 48kHz.

| Scenario | Maximum callback | Maximum with overhead | Budget used |
| --- | ---: | ---: | ---: |
| Startup | 1,938 | 2,669 | 66.7% |
| Manual changes | 2,506 | 3,237 | 80.9% |
| Automatic changes | 2,514 | 3,245 | 81.1% |

This model excludes physical bus/DMA contention. The bottom-right LED remains
an on-card callback timing warning; hardware testing is still required.

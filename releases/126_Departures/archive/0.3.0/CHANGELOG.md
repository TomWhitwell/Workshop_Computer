# Changelog

## 0.3.0 — 8 November 2026

Promote the accepted bell-phrasing experiment to stable, with the exact same
firmware bytes. Includes shared-tone chord transitions, a slow tide, layer rests,
stored bell accents, occasional octave answers and single-step note mutations.
Preserves the quieter bell balance and stronger external effects send.

The public README and catalogue metadata now describe 0.3.0. Previous stable and
experimental releases are under `archive/`; the CV2 destination experiment is
separate in `experimental/0.4/`.
